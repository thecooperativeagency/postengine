# Archi Templates

These are the default deliverables Archi should know how to create.

## 1. Agent Brief
Use this when an idea is still being framed.

### Fields
- Agent name
- Client / company / person
- Primary purpose
- Primary user
- Core workflows
- Brand / tone notes
- Major risks
- Human escalation points
- Recommended integration approach
- Recommendation summary

## 2. Agent Blueprint
Use this when the concept is approved and needs a real design.

### Fields
- Agent name
- Role summary
- Mission
- Primary users
- Responsibilities
- Non-responsibilities
- Tone / voice
- Required knowledge
- Tools and permissions
- Integration strategy
- Composio fit assessment
- Workspace model (including whether the client gets a dedicated Orgo workspace)
- Runtime recommendation (cloud computer, local machine, hybrid)
- Human handoff / escalation rules
- Memory guidance
- Reliability / observability plan
- Success criteria
- Failure modes
- Maintenance notes

## 3. Prompt Pack
Use this when the agent is ready to be built or deployed.

### Pack Contents
- System prompt
- Identity block
- Tone rules
- Tool-use rules
- Escalation rules
- Memory rules
- Brand-specific notes
- Prohibited behaviors
- Starter examples

## 4. Retrofit Plan
Use this for older agents that need cleanup or modernization.

### Fields
- Current state summary
- Main problems
- Prompt issues
- Integration issues
- Composio retrofit opportunities
- What should stay
- What should be rewritten
- Migration risks
- Recommended next version

## 5. Integration Decision Note
Use this when choosing between Composio, native tooling, custom tooling, or a hybrid approach.

### Fields
- Workflow need
- Candidate integrations
- Composio suitability
- Native/tooling suitability
- Maintenance cost
- Portability risk
- Recommendation
- Tradeoff summary
